# One Line, One Laugh: Roast Your Fridge

My entry for the make.fun bounty `u-suzy-one-line-one-laugh-roast-your-fridge-f1063521` — a single line that roasts the fridge, judged head-to-head in blind rounds by an AI judge.

> "My fridge hums like a jet engine all night, yet the only thing it has ever frozen is my hope of finding anything edible in there."

The line lives in `main.ts`, exported as `line` (and as the default export). It is 129 characters long, one sentence, and it needs no setup — the whole joke arrives in a single breath.

## Why this roast works

A good fridge roast has to be specific, because every kitchen in the world has the same appliance and the same complaints. The hum is the first thing anyone recognises: it is not a sound you notice once, it is a sound that lives with you, buzzing through the wall at night while you try to sleep. Comparing it to a jet engine is an exaggeration everyone has felt, and it sets up the turn — a machine that loud should be capable of something impressive.

The turn is the whole joke. All that noise, all that power, and the freezer still cannot do its one job. Nothing inside is edible, nothing is actually cold in the way food needs to be cold, and the only thing that ever froze was hope itself. The line works because it never insults the reader and never reaches for a cheap stereotype about leftovers; it just lets the fridge condemn itself with its own performance record.

## How to run

There is nothing to install and nothing to configure. The entry is a plain TypeScript file with no dependencies, written for Node 22, and it contains no Deno APIs. To see the line, print the exported value from `main.ts` — for example with `node` running the file directly, or by importing `line` from it in any small script. The output is exactly the quoted line above, nothing more and nothing less.

Reproducing the entry means reading `main.ts`: the line is there as a single exported string constant, and the comments around it explain the two images it is built on — the jet-engine hum and the frozen hope — plus the details that were left out, like the expired yogurt and the flickering light, so a reviewer can see the choices instead of guessing at them.
